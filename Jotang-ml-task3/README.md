## 实践 1：简单计算链

**文件：** `code/practice1.py`

### 函数

$$f(x, y) = (xy + x^2)^2$$

### 计算步骤

```
step1: a = x * y         # 乘法
step2: b = x²            # 平方
step3: c = a + b         # 加法
step4: f = c²            # 平方
```

### 梯度推导（链式法则）

$$\frac{\partial f}{\partial x} = 2c \cdot (y + 2x) = 2(xy + x^2)(y + 2x)$$

$$\frac{\partial f}{\partial y} = 2c \cdot x = 2x(xy + x^2)$$

### 验证结果

| x | y | NumPy 手算 | PyTorch | 数值差分 | 最大误差 |
|---|---|-----------|---------|---------|---------|
| 2.0 | 3.0 | ✅ | ✅ | ✅ | 0.00e+00 |
| -1.5 | 0.5 | ✅ | ✅ | ✅ | 0.00e+00 |
| 0.7 | 4.2 | ✅ | ✅ | ✅ | 3.45e-06 |
| 3.0 | -2.0 | ✅ | ✅ | ✅ | 0.00e+00 |

三种方法结果一致，误差在浮点精度范围内。

## 实践 2：两层神经网络梯度

**文件：** `code/practice2.py`

### 网络结构

```
X → Linear → ReLU → Linear → Sigmoid → BCE
```

### 参数与形状

| 参数 | 形状（单样本） | 形状（batch=4） | 说明 |
|------|-------------|---------------|------|
| X | (1, 2) | (4, 2) | 输入 |
| W1 | (2, 4) | (2, 4) | 第一层权重 |
| b1 | (4,) | (4,) | 第一层偏置 |
| W2 | (4, 1) | (4, 1) | 第二层权重 |
| b2 | (1,) | (1,) | 第二层偏置 |

### 梯度推导（Sigmoid + BCE 简化）

$$\frac{\partial L}{\partial z} = \frac{p - y}{N}$$

**完整反向传播路径：**

```
∂L/∂z = -(y-p)/N                    ← ② Sigmoid+BCE 简化
∂L/∂W2 = a.T @ ∂L/∂z               ← ③
∂L/∂b2 = Σ ∂L/∂z                   ← ④
∂L/∂a = ∂L/∂z @ W2.T               ← ⑤
∂L/∂h = ∂L/∂a * relu'(h)           ← ⑥
∂L/∂W1 = X.T @ ∂L/∂h               ← ⑦
∂L/∂b1 = Σ ∂L/∂h                   ← ⑧
```

### 验证结果

| 测试 | 参数 | NumPy 形状 | PyTorch 形状 | 最大误差 | 结果 |
|------|------|-----------|-------------|---------|------|
| 单样本 | dW1 | (2,4) | (2,4) | 0.00e+00 | ✅ |
| 单样本 | db1 | (4,) | (4,) | 0.00e+00 | ✅ |
| 单样本 | dW2 | (4,1) | (4,1) | 2.78e-17 | ✅ |
| 单样本 | db2 | (1,) | (1,) | 0.00e+00 | ✅ |
| batch=4 | dW1 | (2,4) | (2,4) | 1.39e-17 | ✅ |
| batch=4 | db1 | (4,) | (4,) | 0.00e+00 | ✅ |
| batch=4 | dW2 | (4,1) | (4,1) | 1.39e-17 | ✅ |
| batch=4 | db2 | (1,) | (1,) | 0.00e+00 | ✅ |

**所有梯度与 PyTorch autograd 一致，误差在浮点精度范围内。**

### 形状对比观察

```
参数       单样本 shape    batch shape
─────────────────────────────────────
dW1      (2, 4)          (2, 4)       ← 形状不变！
db1      (4,)            (4,)         ← 形状不变！
dW2      (4, 1)          (4, 1)       ← 形状不变！
db2      (1,)            (1,)         ← 形状不变！
```

**关键发现：** 参数梯度形状由网络结构决定，与 batch size 无关。Batch 维度通过矩阵乘法被"消掉"了。
