# Git 学习笔记

## 什么是 Git？

Git 是一个分布式版本控制系统，用来记录和管理文件的版本变更。
它可以帮助开发者记录"改了什么"，并在需要时找回之前的版本。

**Git ≠ GitHub**
- **Git**：负责本地版本控制（记录和管理文件版本）
- **GitHub**：在线代码托管平台，用于分享和协作

## 我使用过的 Git 命令

### 1. 初始化仓库

```bash
git init
```

在当前目录创建一个 `.git` 文件夹，这个目录就变成了一个 Git 仓库。

### 2. 查看仓库状态

```bash
git status
```

显示当前工作区有哪些文件被修改、新增或未追踪。

### 3. 将文件加入暂存区

```bash
git add <文件名>     # 添加指定文件
git add .           # 添加当前目录下所有文件
```

文件先加入"暂存区"，再做提交，这样可以有选择地提交文件。

### 4. 提交到本地仓库

```bash
git commit -m "提交说明"
```

将暂存区的内容保存到本地仓库。提交信息（message）建议用简短的话说明本次改了什么。

### 5. 连接远程仓库

```bash
git remote add origin <仓库地址>
```

把本地仓库和 GitHub 上的仓库关联起来。仓库地址在 GitHub 仓库页面上可以找到。

### 6. 推送到 GitHub

```bash
git push -u origin main
```

将本地仓库的提交同步到 GitHub。`-u` 表示首次推送时建立分支跟踪关系。

### 7. 查看提交历史

```bash
git log
```

查看所有的提交记录，包括每次提交的哈希值、作者和时间。

## 小贴士

- 提交前用 `git status` 确认一下改了哪些文件，避免不小心提交多余内容
- Commit message 写清楚比写 "update" 或 "final" 好得多
- 不在公开仓库上传密码、Token、API Key 等敏感信息
- 如果不小心提交了敏感信息，立即修改并用新提交覆盖，必要时轮换密码
